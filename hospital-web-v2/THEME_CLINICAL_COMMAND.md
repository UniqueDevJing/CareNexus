# CareNexus 视觉主题：临床智能中枢

## 主题定位

CareNexus 不是普通医院门户，而是患者、医生与 AI Agent 共用的临床工作空间。界面要传达三件事：系统可信、信息可追溯、关键操作明确。

主题使用深海军蓝承载 Agent 状态和系统链路，手术绿表示安全、在线和可执行动作，医疗白承载高密度临床信息。警告色仅用于确实需要注意的状态，不能装饰性使用。

## 角色体验

- 管理员：强调 Agent 运行链路、容量、失败定位和可观测性。深色中枢区可以出现，但数据阅读面保持白色。
- 医生：优先展示患者队列、危急信息和病历编辑，减少装饰，重要操作固定在工作流末端。
- 患者：使用更明亮的表面、更自然的语言和明确的隐私提示；不暴露内部模型术语。

## 版式与组件

- 正文字号不低于 13px；状态、代码和元数据不低于 12px。
- 标题使用 Bahnschrift / 中文系统无衬线字体，正文使用 MiSans 或系统中文字体。
- 页面采用 8px 基础节奏；主要面板圆角 18px，内部控件 8–12px。
- 同一屏只允许一个主操作。次级操作使用描边或文本样式。
- 卡片用于独立任务或数据单元，不把每段文字都包成卡片。
- 状态不能只依赖颜色，必须同时提供文字、图形或结构差异。

## 动效和无障碍

- 页面进入动效控制在约 480ms，使用位移和透明度，尊重 `prefers-reduced-motion`。
- 悬停只做 1–2px 位移或轻微底色变化，不做大幅缩放。
- 所有键盘焦点使用手术绿 2px 焦点环。
- 应用提供“跳到主要工作区”链接；移动导航同步暴露展开状态和动态标签。

## 验收基线

- 桌面：1440×900、1024×768。
- 平板：820×1180、768×1024。
- 手机：390×844。
- 三种角色均需验证：管理员、医生、患者。
- 危急、警告、正常和禁用状态需要同时检查文字可读性和键盘操作。
