# CareNexus 部署指南

## 构建

```bash
cd hospital-v2
mvn -B clean package -DskipTests
cd ../hospital-web-v2
npm ci && npm run build
```

## Docker Compose

```bash
cp .env.example .env
docker compose --env-file .env -f deploy/docker-compose.yml up -d --build
```

访问 `http://服务器/CareNexus/`；后端 API 通过 `/v2/api` 反向代理。该示例入口只有 HTTP，因此 `.env` 中必须使用 `AUTH_COOKIE_SECURE=false`，否则浏览器会拒收 HttpOnly 登录 Cookie。

生产环境应在 Nginx、云负载均衡或网关层终止 TLS，并将外部入口切换为 HTTPS；只有确认 HTTPS 已生效后，才将 `AUTH_COOKIE_SECURE=true`。仓库不包含证书，也不会把 HTTP 配置伪装成 HTTPS。

## 非容器部署

- 后端：使用 Java 21 启动 `hospital-v2/target/hospital-v2.jar`，启用 `mysql` profile。
- 前端：将 `hospital-web-v2/dist` 部署到 Nginx 的 `/CareNexus/` 目录。
- Nginx：将 `deploy/nginx.conf` 中的 `backend` 上游改为本机后端地址。

生产环境必须替换 JWT 密钥、数据库密码和阿里云百炼 API Key；不要把 `.env` 提交到 Git。
